# E'Magios Core — Официальный сайт

Официальный веб-сайт настольной ролевой системы **E'Magios Core**.

🌐 **Live Site:** [https://kaliguri.github.io/E-Magios-Core-Site/](https://kaliguri.github.io/E-Magios-Core-Site/) *(после настройки GitHub Pages)*

## О проекте

E'Magios Core — это настольная ролевая система о магах, которые создают свои уникальные заклинания и исследуют мир магии.

Этот сайт включает:
- 📖 **Player's Handbook** — правила для игроков (11 глав)
- 🎲 **Master's Handbook** — руководство для мастера (защищено паролем)
- ✨ **Spellbook** — 41 школа магии и заклинания (защищено паролем)
- 🔨 **Craftbook** — ремёсла и создание артефактов (защищено паролем)
- 📜 **Compendium of Rumors** — дополнительные материалы (защищено паролем)
- 👤 **Редактор персонажей** — создание и управление персонажами с автоматическими расчётами
- 🔍 **База данных** — поиск и фильтрация заклинаний, школ магии и эффектов

## Технологии

- **HTML5** + **CSS3** + **Vanilla JavaScript**
- Без фреймворков, без зависимостей, без сборщиков
- Темная тема с изумрудными акцентами
- Полностью статический сайт

## Локальная разработка

### Запуск локального сервера

```bash
# Python 3
cd C:\Gamedev\E-Magios-Core-Site
python -m http.server 8000

# Затем откройте http://localhost:8000
```

**Важно:** Всегда тестируйте через локальный сервер (`http://`), а не через `file://` протокол!

### Проверка изменений

1. Внесите изменения в HTML/CSS/JS файлы
2. Обновите страницу в браузере (Ctrl+F5 для жесткого обновления)
3. Проверьте консоль браузера (F12) на ошибки

## Развёртывание на GitHub Pages

### Первоначальная настройка

1. **Инициализируйте Git репозиторий:**
   ```bash
   cd C:\Gamedev\E-Magios-Core-Site
   git init
   git add .
   git commit -m "Initial commit: E'Magios Core website"
   ```

2. **Подключите к GitHub:**
   ```bash
   git remote add origin https://github.com/Kaliguri/E-Magios-Core-Site.git
   git branch -M main
   git push -u origin main
   ```

3. **Настройте GitHub Pages:**
   - Откройте: **Settings** → **Pages**
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` → **Folder**: `/ (root)`
   - Нажмите **Save**

4. **Сайт будет доступен через 1-2 минуты:**
   ```
   https://kaliguri.github.io/E-Magios-Core-Site/
   ```

### Обновление сайта

```bash
# 1. Внесите изменения в файлы

# 2. Закоммитьте изменения
git add .
git commit -m "Update: описание изменений"

# 3. Отправьте на GitHub
git push origin main

# 4. Через 1-2 минуты изменения появятся на сайте
```

## Работа с контентом

### Добавление новых заклинаний

Отредактируйте `data/spells.json`:

```json
{
  "id": "unique-id",
  "name": "Название заклинания",
  "rarity": "Редкая|Эпическая|Скрытая",
  "range": "Ближняя|Средняя|Дальняя",
  "type": "Атака|Защита|Контроль|Поддержка",
  "school": "Название школы",
  "source": "Учебное|Фирменное",
  "actions": 1,
  "concentration": false,
  "duration": "Мгновенно",
  "damageTypes": ["Аркана"],
  "description": "Описание заклинания"
}
```

### Конвертация Markdown → HTML

При добавлении нового контента из Obsidian Vault:

1. Откройте исходный MD файл в Obsidian Vault
2. Конвертируйте согласно правилам:
   - `## Заголовок` → `<h2>Заголовок</h2>`
   - `**жирный**` → `<strong>жирный</strong>`
   - `[[Ссылка|текст]]` → `<a href="#id">текст</a>`
   - Таблицы → HTML `<table>`
3. Добавьте в соответствующий HTML файл
4. Обновите TOC (содержание) если нужно

### Обновление защищённых страниц

Пароль для Master/Spellbook/Craftbook/Rumors: **147**

Если нужно изменить пароль, отредактируйте в `common.js`:
```javascript
const MASTER_PASSWORD = '147';
```
