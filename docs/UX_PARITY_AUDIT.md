# UX-аудит паритета: Legacy → React

> Ветка `migration/phases-0-1-2`, дата 2026-06-03.
> Фокус: тонкий UX (расположение, цветовая подводка, кликабельность, микро-взаимодействия),
> а не крупные фичи (их закрывали фазы 1–6, см. `MIGRATION_GAP_ANALYSIS.md`).
> Верификация: визуальный прогон обеих версий (React `:5173/#/db`, legacy `:8000/db.html`).
> Решения пользователя: смело улучшать сверх легаси; начать с БД; сначала весь аудит, потом правки.

Легенда: 🔴 ломает ощущение продукта · 🟠 заметная потеря удобства · 🟡 косметика/полировка.
Статус: `[ ]` не сделано · `[x]` сделано · `[~]` осознанно отложено.

## Итог реализации (2026-06-03)

Отгружено в этой сессии:

- **D1** [x] — Школа/Тип/Дистанция/Цель/Ресурсы/Концентрация в попапах БД теперь
  кликабельные emerald-кросс-ссылки (`EntityRefLink`/`LinkedValue`), открывают
