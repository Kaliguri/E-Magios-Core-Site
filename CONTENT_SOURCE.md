## Требования к оформлению

**Источник:** `E'Magios Core/099. Требования к оформлению.md`

Этот файл содержит правила оформления контента в Markdown, которые нужно учитывать при конвертации в HTML.

## Процесс обновления контента

1. **Редактирование контента**
   - Открыть Obsidian Vault
   - Отредактировать нужные Markdown файлы
   - Сохранить изменения

2. **Конвертация в HTML**
   - Открыть соответствующий HTML файл в этом репозитории
   - Вручную конвертировать Markdown → HTML
   - Следовать правилам из `099. Требования к оформлению.md`

3. **Обновление JSON данных**
   - Для заклинаний: обновить `data/spells.json`
   - Для школ магии: обновить `data/schools.json`
   - Для эффектов: обновить `data/effects.json`

4. **Публикация**
   ```bash
   git add .
   git commit -m "Update: [описание изменений]"
   git push origin main
   ```

## Правила конвертации

### Markdown → HTML

| Markdown | HTML |
|----------|------|
| `## Заголовок` | `<h2>Заголовок</h2>` |
| `#### Подзаголовок` | `<h4>Подзаголовок</h4>` |
| `**жирный**` | `<strong>жирный</strong>` |
| `*курсив*` | `<em>курсив</em>` |
| `- пункт` | `<ul><li>пункт</li></ul>` |
| `[[Ссылка\|текст]]` | `<a href="#id">текст</a>` |
| Таблица MD | `<table>...</table>` |

### Wikilinks → Якоря

Obsidian использует wikilinks формата `[[Файл|Текст]]`.

**Конвертация:**
- `[[03. Характеристики|Характеристики]]` → `<a href="#stats">Характеристики</a>`
- `[[Школа Магии - Базовая Аркана|Базовая Аркана]]` → ссылка на db.html или описание в spellbook.html
